# E-Commerce API

A scalable E-Commerce Backend API built with Node.js, TypeScript, Express, and PostgreSQL.

## Features

- User Authentication (JWT)
- Product Management
- Categories
- Shopping Cart
- Orders
- Payments
- Reviews
- Coupons
- Inventory Management
- Swagger API Documentation

## Tech Stack

- Node.js
- TypeScript
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication
- Swagger

## Architecture

Route → Controller → Service → Repository → Database
